# Stealth Flock

Stealth Flock is a lightweight, browser-based navigation tool that helps you find the quickest route to your destination while avoiding known Flock Safety camera locations along the way — helping you protect your privacy and keep your movement data out of automated surveillance networks.

## Features

- 📍 **Route planning** — Get the fastest route between your current location and a destination.
- 🚫 **Camera avoidance** — Routes are calculated to steer around known Flock camera locations.
- 🎨 **Clean, professional UI** — Simple, distraction-free interface built for quick use on the go.
- ⚡ **Lightweight** — Runs entirely from a single `index.html`, no heavy frameworks or build steps required.
- 🔒 **Privacy-first** — No user location data or search history is collected or stored.
